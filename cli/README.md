# День 26. Запуск локальной LLM — llmcli

Локальная LLM `qwen2.5:3b` в [Ollama](https://ollama.com) на видеокарте и CLI к ней на Python (только стандартная
библиотека). Модель отвечает без интернета и без ключей, обращение — по HTTP API Ollama.

| | |
|---|---|
| Сервер | Ollama 0.40.1, `http://127.0.0.1:11434` (служба Windows, стартует сама) |
| Модель | `qwen2.5:3b` — Qwen 2.5, 3,1 млрд параметров, Q4_K_M, 1,9 ГБ на диске, контекст модели 32 768 токенов |
| Железо | GTX 1050 Ti 4 ГБ — модель целиком в видеопамяти (2,0 ГБ с окном 4096) |
| Скорость | ≈28–37 токенов/с; первый токен 0,1–0,25 с; холодная загрузка модели ≈20 с |

## Установка

```bash
winget install Ollama.Ollama
ollama pull qwen2.5:3b
```

## CLI

```bash
python cli/llmcli.py ask "Что такое горутина?"                          # ответ печатается по мере генерации
python cli/llmcli.py ask --stats --temperature 0 --seed 1 --max-tokens 200 "Придумай название кофейни"
type main.py | python cli/llmcli.py ask "Найди ошибки в коде"            # текст из конвейера + задание
python cli/llmcli.py ask --json "Верни JSON с ключами city и country для Эйфелевой башни"
python cli/llmcli.py models                                             # модели и что сейчас в видеопамяти
python cli/llmcli.py bench                                              # 6 запросов разной сложности с проверкой
python cli/llmcli.py help                                               # справка, сведения о модели, ограничения
```

`cli\llmcli.bat` — то же самое двойным кликом / из `cmd` с UTF-8. Другая модель: `--model llama3.2:3b` или
переменная `LLM_MODEL`; другой адрес Ollama — `OLLAMA_URL`.

Флаги `ask`: `--system`, `--temperature`, `--top-p`, `--top-k`, `--repeat-penalty`, `--ctx` (num_ctx),
`--max-tokens` (num_predict), `--seed`, `--stop` (можно повторять), `--json` (format=json), `--stats`
(токены запроса/ответа, ток/с, время до первого токена и загрузки модели — в stderr). Если модели нет,
`ask` и `bench` скачивают её сами.

## HTTP API напрямую

```powershell
# тело запроса — из файла в UTF-8: в Windows-консоли кириллица в аргументе curl может испортиться
curl.exe -s http://127.0.0.1:11434/api/generate -H "Content-Type: application/json" --data-binary "@cli/examples/generate.json"
curl.exe -s http://127.0.0.1:11434/api/chat     -H "Content-Type: application/json" --data-binary "@cli/examples/chat.json"
curl.exe -s http://127.0.0.1:11434/v1/chat/completions -H "Content-Type: application/json" -d "{\"model\":\"qwen2.5:3b\",\"messages\":[{\"role\":\"user\",\"content\":\"2+2? Answer with a number.\"}]}"
```

| Эндпоинт | Запрос | Ответ модели |
|---|---|---|
| `/api/generate` | «Назови три планеты Солнечной системы через запятую.» | «Меркурий, Венера, Земля» (14 токенов, 29,8 ток/с) |
| `/api/chat` | «Объясни одним предложением, что такое HTTP API.» | «HTTP API — это набор команд и протоколов для взаимодействия между клиентом и сервером через HTTP.» |
| `/v1/chat/completions` (OpenAI-совместимый) | «2+2=? Ответь числом.» | «2+2=4» |

## Запросы разной сложности — `llmcli bench`

`temperature 0`, `seed 42`; каждый ответ проверяется автоматически.

| Уровень | Запрос | Проверка | Итог | Токены | ток/с | 1-й токен | Всего |
|---|---|---|---|---:|---:|---:|---:|
| простой | «Какая столица Франции? Ответь одним словом.» | есть «Париж» | ✓ «Париж» | 4 | 36,9 | 0,09 с | 0,2 с |
| простой | «Сколько будет 17 * 23? Ответь только числом.» | число = 391 | ✓ «391» | 4 | 36,8 | 0,11 с | 0,2 с |
| средний | задача про яблоки в 3 шага (120 − ¼ + 45 − 30) | итог = 105 | ✓ решение по шагам, «Ответ: 105» | 152 | 27,9 | 0,23 с | 5,7 с |
| средний | извлечь name/age/city из фразы в JSON (`format=json`) | значения совпали | ✓ `{"name": "Анна", "age": 34, "city": "Казань"}` | 30 | 28,6 | 0,17 с | 1,2 с |
| сложный | функция `is_palindrome` без import | код запускается и проходит 5 тестов | ✓ все тесты, в т.ч. «А роза упала на лапу Азора» | 41 | 28,3 | 0,24 с | 1,7 с |
| сложный | логика: кто какой напиток пьёт | ответ «кофе» | ✓ рассуждение и «Ответ: кофе» | 61 | 28,1 | 0,24 с | 2,4 с |

**Верно 6 из 6.** Код из ответа модели запускается в отдельном процессе Python (`-I`, таймаут 10 с, временная папка)
и только если в нём нет ничего, кроме определений функций.

**Ограничения модели** (видно и в работе): маленькая 3B-модель уверенно выдумывает факты — на вопрос «что делает этот
файл?» про `llmcli.py` она ответила, что это CLI для LLM «компании Anthropic»; плохо пересказывает длинный английский
текст по-русски (см. Дни 22–25); не знает ничего после даты обучения; каждый `ask` независим.
